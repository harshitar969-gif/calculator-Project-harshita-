# 🧮 Calculator - By Harshita | MCA

A modern, responsive calculator built with HTML5, CSS3 & JavaScript.
Live Demo: Will be available after GitHub Pages deploy

### ✨ Features
- ➕ Basic Operations: Add, Subtract, Multiply, Divide, %
- 🧹 Clear (C) & Delete (⌫) functionality
- ⌨️ Full Keyboard Support (Type numbers directly!)
- 📱 100% Responsive - Works on Mobile & Laptop
- 🌙 Modern Dark UI with Hover Effects

### 🛠️ Tech Stack
- **Frontend:** HTML5, CSS3 (Grid & Flexbox)
- **Logic:** JavaScript (Vanilla) - eval() & DOM Manipulation
- **Tools:** VS Code, Live Server, Git & GitHub

### 📁 Project Structure
Calculator-Project-Harshita/
├── index.html   # Main structure
├── style.css    # Styling & Responsive Design
├── script.js    # Calculation Logic
└── README.md

### 🚀 How to Run
1. Clone or Download this repo
2. Open folder in VS Code
3. Open `index.html` with Live Server
4. Or just double-click `index.html`
